Detailed Description

Vaizduoja studentą su namų darbų pažymiais ir galutiniu balu.

Paveldi iš Zmogus ir papildo namų darbų pažymiais, egzamino balu bei apskaičiuotais galutiniais balais (vidurkiu ir mediana). Realizuota pilna Rule of Five: kopijavimo/perkėlimo konstruktoriai, priskyrimo operatoriai ir destruktorius.
